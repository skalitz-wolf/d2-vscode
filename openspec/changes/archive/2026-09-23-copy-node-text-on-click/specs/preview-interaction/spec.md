# Spec Delta

## Purpose

定义 D2 预览面板内的鼠标交互契约：平移拖动、缩放、文字选中复制、超链接角标跳转、场景切换，以及各交互在同一次鼠标动作上的优先级与冲突消解规则。

## ADDED Requirements

### Requirement: 单击文字复制该段文字

预览面板 SHALL 在用户单击 SVG 文字时，把该文字元素的完整文本内容写入系统剪贴板。

- 文字内容按 d2 渲染出的文字元素边界界定：一次单击对应一个 `<text>` 元素的全部内容。
- 多行文字（d2 将每行渲染为独立的行元素）SHALL 按视觉顺序用换行符连接后复制，而不是无分隔符拼接。
- 富文本节点被渲染为多个并列文字元素时，复制内容为该次单击命中的那一个元素，与"复制整行"语义一致。
- 该行为 MUST NOT 依赖扩展端新增消息通道，剪贴板写入在预览页内完成。

#### Scenario: 单击单行标签

- **WHEN** 用户单击一个显示单行文字（如 `hello world`）的节点
- **THEN** 剪贴板内容为 `hello world`

#### Scenario: 单击多行标签

- **WHEN** 用户单击一个由三行组成的节点标签 `alpha` / `beta` / `gamma`
- **THEN** 剪贴板内容为三行文本，行间以换行符分隔，而不是 `alphabetagamma`

#### Scenario: 单击富文本节点中的一片文字

- **WHEN** 用户单击一个 markdown 富文本节点中显示为粗体的那段文字
- **THEN** 剪贴板内容为该段文字本身，不包含同节点内其他并列文字片段

#### Scenario: 剪贴板写入不可用

- **WHEN** 剪贴板写入失败（如 API 被拒绝或不可用）
- **THEN** 预览页回退到等效的复制手段，且不抛出未捕获异常、不中断预览交互

### Requirement: 复制操作的就地反馈

预览面板 SHALL 在复制发生后给出可被用户察觉的就地视觉反馈，指明被复制的是哪一段文字。

- 反馈 MUST 不覆盖或替换预览面板已有的加载中提示与编译错误提示内容。
- 悬停在文字上时，光标 SHALL 保持文本选择语义（而非抓取语义），不额外引入复制专用的光标样式。

#### Scenario: 复制成功后高亮

- **WHEN** 单击文字并成功写入剪贴板
- **THEN** 被复制的文字短暂高亮后自动恢复原样

#### Scenario: 悬停文字时的光标语义

- **WHEN** 鼠标悬停在 SVG 文字上且未处于拖动状态
- **THEN** 光标为文本选择语义（与可划选一致），而非抓取语义

#### Scenario: 反馈不破坏错误提示

- **WHEN** 预览正在显示编译错误提示，用户单击图上的文字完成复制
- **THEN** 复制反馈出现，且错误提示内容仍然可见

### Requirement: 已有选区优先于复制

当页面上已存在非折叠的文字选区时，单击 MUST NOT 覆盖该选区的内容，也 MUST NOT 触发复制。

#### Scenario: 划选后单击不覆盖

- **WHEN** 用户先划选了一段文字，随后在另一处文字上单击
- **THEN** 不写入剪贴板，原有选区保持

### Requirement: 拖动平移与文字复制的分流

预览面板 SHALL 按点击目标决定鼠标左键按下的语义，保持既有交互互不吞并。

- 按在文字元素上：不启动平移，放行浏览器原生文字选择。
- 按在框体或空白处：启动平移拖动，并清除已有文字选区。
- 平移进行中：禁止文字选择，光标保持抓取语义。

#### Scenario: 框体拖动仍然平移

- **WHEN** 用户在节点框体（非文字）上按下左键并移动鼠标
- **THEN** 预览图随之平移，且不产生文字选区

#### Scenario: 文字上按下不触发平移

- **WHEN** 用户在节点文字上按下左键并拖动
- **THEN** 预览图不移动，浏览器原生文字选择生效

#### Scenario: 平移中经过文字

- **WHEN** 正在平移预览图，鼠标经过某段文字
- **THEN** 光标保持抓取语义，且不选中经过的文字

### Requirement: 超链接角标跳转优先于复制

单击 d2 自带的超链接角标（`.appendix-icon`）SHALL 触发 board 跳转，MUST NOT 触发复制或平移。

#### Scenario: 单击角标跳转

- **WHEN** 用户单击节点右上角的超链接角标
- **THEN** 预览切换到该链接指向的 board，剪贴板内容不变

#### Scenario: 角标按下不启动平移

- **WHEN** 用户在超链接角标上按下左键并移动鼠标
- **THEN** 预览图不平移，松开后跳转正常触发

### Requirement: 双击选词与复制的共存

双击文字 SHALL 仍完成原生选词；由此附带触发的复制 MUST NOT 阻断选词结果或破坏预览状态。

#### Scenario: 双击选中一个词

- **WHEN** 用户双击某段文字中的一个词
- **THEN** 该词被选中，预览图不移动，且页面处于可用状态（无未捕获异常）

### Requirement: 缩放与平移状态不受复制影响

复制相关交互 MUST NOT 改变当前缩放比例、平移位置或适配模式。

#### Scenario: 复制后视图不变

- **WHEN** 用户已缩放并平移到一个特定位置，随后单击文字完成复制
- **THEN** 缩放比例与平移位置保持不变，预览不重新适配
